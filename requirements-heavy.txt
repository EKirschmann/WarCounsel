# The OCR build (WarCounsel-OCR.zip) — everything the lean exe does, PLUS
# screen reading. This file IS the contract for what that build can do, the
# way requirements-lite.txt is for WarCounsel.exe.
#
# Why this is a SEPARATE download rather than the default:
#
#   measured 2026-08-08, installed size beside a 43.6 MB WarCounsel.exe
#     cv2 (opencv-python)     112.4 MB   required by rapidocr; we never
#                                        import it ourselves
#     onnxruntime              42.5 MB
#     numpy                    30.8 MB
#     rapidocr_onnxruntime     15.6 MB   includes the ONNX models
#     mss                       0.4 MB   the screen grab itself
#                             --------
#                             204.6 MB
#
# The download size is not the real cost — the COLD START is. A --onefile
# bundle re-extracts itself to a temp dir on EVERY launch, which is what
# makes the lean exe take ~4s, and that scales with payload. Adding 200 MB
# to the default build would slow every launch for everyone, including the
# majority who never turn screen reading on. So this build is BOTH separate
# AND --onedir: extracted once, launched instantly thereafter.
#
# opencv-python-headless is NOT used and would not help: measured at
# 112.0 MB against 112.4 MB, because on Windows it ships the identical
# 82 MB cv2.pyd. The ~40 MB figure quoted for it is the WHEEL, not the
# installed size. What IS removable is opencv's 29.4 MB video codec DLL
# (opencv_videoio_ffmpeg*.dll) — OCR on still screenshots cannot need it,
# and the build deletes it with a CI assertion to keep that honest.

-r requirements-lite.txt

# --- screen reading (this is the whole difference) ---------------------
mss>=9.0
numpy
# rapidocr renamed between Python versions; both are the same engine. The
# Windows OCR engine is deliberately NOT used instead — it silently drops
# short lines like "Z: 4", which is exactly the data this reads.
rapidocr-onnxruntime>=1.3; python_version < "3.13"
rapidocr>=2.0; python_version >= "3.13"
onnxruntime>=1.20; python_version >= "3.13"
