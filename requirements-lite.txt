# The lean set for the single executable: no OCR, but LLM counsel included.
# Everything runs: HUD, War Ledger, encounters, Atlas (charts/true-walls/3D),
# spellbook/inventory/AA parsing, the advisor & gear (deterministic OR an
# LLM), spell-set writing, update checks. Position comes from /loc lines
# (no screen OCR).
# Omitted vs requirements.txt: rapidocr/onnxruntime/mss/numpy (OCR),
# langgraph (the tab-less chat agent), mcp (unused — wiki uses plain HTTP).
#
# The LLM clients are NOT optional here: the settings panel offers an API
# key field, and PyInstaller only bundles what the build machine has
# installed — leaving them out produced an exe whose key field could never
# do anything, depending on who built it.
fastapi>=0.104.0
uvicorn[standard]>=0.24.0
sqlalchemy>=2.0.0
pydantic>=2.5.0
pydantic-settings>=2.1.0
aiohttp>=3.9.0
python-dotenv>=1.0.0
psutil>=5.9
certifi>=2024.0
# Atlas 3D texture export (BMP->PNG). Without it the 3D view still
# renders, just untextured.
pillow>=10.0
# Advisor models. Without these the gear panel greys the LLM options out
# and counsel falls back to the deterministic advisor.
langchain-openai>=0.2
langchain-anthropic>=0.3
# Ollama. Included for the same reason as the others, and more so: it is
# the only provider needing NO key and NO account, which is the best fit
# for the audience that downloads a single .exe. 31 KB plus one small
# HTTP client -- langchain-core is already here.
langchain-ollama>=1.0
# Overlay tray icon. pystray imports its platform backend lazily, so a
# packaged build also needs --hidden-import pystray._win32.
pystray>=0.19
