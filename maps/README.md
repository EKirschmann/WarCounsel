# Bundled maps

Charts for zones the game does not ship one for. Searched **last**, after
your custom pack (Brewall) and the stock `<game>/maps` folder, so anything
you install yourself always wins.

- `newsebexp.txt` — **New Sebilis Expedition**, the EQL-only Iksar city off
  Northern Desert of Ro. The game ships its geometry (`newsebexp.s3d`, so
  the 3D view works without this file) but no chart, which left the 2D view
  blank. Community-contributed.

To use your own instead, drop it in `<game>/maps` — no config needed.
